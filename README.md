📒 Contact Book

A modern desktop Contact Book application built with Python, Tkinter, and SQLite for efficiently managing personal contacts.

✨ Features

- ➕ Add new contacts
- ✏️ Edit existing contacts
- 🗑️ Delete contacts with confirmation dialog
- 🔍 Search contacts instantly
- 📋 Display all contacts in a clean table
- 👤 Auto-generated unique ID for each contact
- 📊 Live contact counter
- 💾 Data stored permanently using SQLite
- 🖥️ Simple and user-friendly graphical interface
- ⚠️ Input validation and error handling
- 🚀 Fast and lightweight

🛠️ Built With

- Python
- Tkinter
- SQLite3
